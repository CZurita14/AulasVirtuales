1. Tus datos

Con tu sílabo, la dirección de tu curso y tu token, cargamos los momentos en tu aula. Nada se publica sin que lo apruebes en el paso 4.

📄 Arrastra tu sílabo aquí o haz clic para elegirlo
El PDF que genera el sistema académico (secciones I a VII).
Entra a tu curso y copia la barra de direcciones.
  1. En Canvas: Cuenta → Configuraciones.
  2. En "Integraciones aprobadas" pulsa + Nuevo token de acceso.
  3. Propósito: Carga de momentos; fecha de expiración: mañana.
  4. Copia el token y pégalo aquí (Canvas solo lo muestra una vez).
🔒 El token solo se usa durante esta sesión para leer tu curso y, cuando lo apruebes, actualizar las páginas Momento. No se guarda. Al terminar puedes eliminarlo en Canvas.
